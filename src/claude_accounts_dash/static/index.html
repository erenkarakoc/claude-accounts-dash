How Brief works. It's a short note built on your computer from the saved transcript, so making it uses no tokens. It includes the project folder and git branch, the files Claude edited, your last 5 requests, the summary Claude wrote if the chat was compacted (trimmed), and Claude's last reply. It also includes the path to the full transcript, so the new session can read more if it needs to. Paste it into a new session in the same project folder on the other account. Claude will check the project, tell you where things stopped, and continue.
